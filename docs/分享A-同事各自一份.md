# 分享方式 A:同事各自擁有一份(資料完全獨立)

每位同事複製一份程式到自己的 Google 帳號部署。筆記資料(試算表、Drive 資料夾)會自動建立在**同事自己的雲端硬碟**,跟你的資料完全無關。

## 你要做的事(一次)

1. 開啟你的 Apps Script 專案(script.google.com → GAS Notion)。
2. 右上「共用」→ 加入同事的 email,權限給「檢視者」即可(只是讓對方能複製,看得到程式碼但改不動你的)。

## 同事要做的事(每人一次,約 5 分鐘)

1. 開啟你分享的 Apps Script 專案連結。
2. 左側「總覽」(ⓘ 圖示)→ 右上「建立副本」→ 得到一份自己的專案。
3. 在自己的副本中:右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」:
   - 執行身分:**我**
   - 誰可以存取:**只有我自己**
   → 按「部署」,過程中會要求授權(出現「Google 尚未驗證這個應用程式」→ 進階 → 前往 → 允許)。
4. 複製 `/exec` 網址,開啟後看到「歡迎使用」頁即完成。把網址加入書籤(或自己嵌到 Google Sites)。

## 注意

- 每人一份程式碼,**日後改版不會自動同步**:你更新後,同事要重新「建立副本+部署」,或把新的 Code.gs / index.html 內容貼進自己的副本再部署新版本。若同事多、常改版,建議改用方式 B。
- 圖片上傳功能會把圖片檔設成「知道連結的人可檢視」(存在各自的「GAS Notion Assets」資料夾),連結無法被猜到,但知道連結的人看得到該圖。
